## Projects

---

### Capstone 1 — Insurance Premium Calculator
A console application that calculates insurance premiums for 
multiple products including vehicle, home and life insurance. 
Applies VAT and generates a formatted client quote.

**Features:**
- Multi-product premium calculation
- VAT application across all products
- Formatted quote output

**Tech:** C#, .NET
**Status:** Complete — Chapter 2

---

### Capstone 2 — Vehicle Risk Assessment Engine
A console application that scores client risk based on age, 
credit score and driving experience. Applies dynamic 
risk-adjusted premiums with VAT.

**Features:**
- Three-factor risk scoring engine
- Age, credit score and experience evaluation
- Dynamic premium adjustment based on total risk score
- Formatted risk report with VAT calculation

**Tech:** C#, .NET
**Status:** Complete — Chapter 4

---

### Capstone 3 — SureGuard Interactive Financial System
A fully interactive console application combining vehicle 
insurance quoting, risk assessment and loan affordability 
checking into a single menu-driven system.

**Features:**
- Multi-module navigation with do/while menu loop
- New Client Quote — vehicle premium with age loading
- Risk Assessment — three-factor scoring with adjusted premium
- Loan Affordability — credit and affordability checks with 
  APPROVED or DECLINED decision
- Input validation using while loops on all user fields
- Credit score bounded validation — 300 to 850
- Age validation — 18 and above enforced
- Console.Clear() for professional UI experience
- Formatted output across all three modules

**Tech:** C#, .NET
**Status:** Complete — Chapter 6
